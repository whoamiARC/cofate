# 因果 CoFate

> 不是和 AI 聊天，是和真人一起掉进同一个 AI 世界。

因果是煜零科技正在开发的 AI 原生文字社交平台。用户通过二维码或邀请码进入同一个临时世界，DeepSeek 根据参与者和主题生成规则怪谈、隐藏身份与共同主线。

它不是 AI 陪聊产品：AI 负责世界，真人负责关系。第一版聚焦线下聚会与在线双人匹配，让手机重新成为人与人连接的媒介。

## 当前 MVP

- 创建私密文字世界并描述主题
- 自动生成邀请码和可扫描二维码
- DeepSeek 按玩家生成仅本人可见的身份、规则和目标
- 所有玩家提交选择后，共同推进一条世界主线
- 一个人也可以进入双人在线匹配
- 实时同步成员、回合、公开规则与私人回声
- 移动端优先，无需注册和下载

## 技术结构

- Next.js / React / TypeScript
- Cloudflare Worker 兼容运行时
- D1 持久化世界、成员和消息
- DeepSeek Chat Completions（默认 `deepseek-v4-flash`）
- 轮询同步，适合低成本早期验证

## 本地运行

```bash
npm install
npm run dev
```

打开 `http://localhost:3000`。

DeepSeek 密钥必须只配置在服务端运行环境中：

```text
DEEPSEEK_API_KEY=你的密钥
```

可选设置 `DEEPSEEK_MODEL` 切换模型。不要将密钥写入前端代码或提交到 Git。

## 产品原则

1. AI 不替代真人关系。
2. 世界是社交场景，不是游戏副本。
3. 用户离开时，应该带走一段共同经历。
4. 第一版先验证“人们是否愿意扫码进入并持续互动”。
