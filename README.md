# 因果 Causality

> 不是和 AI 聊天，是让 AI 帮助我们聊天。

因果是煜零科技正在开发的 AI 原生情境社交平台。用户通过二维码进入同一个临时世界，AI 根据现场的人、关系和互动节奏生成话题、身份与共同经历。

它不是剧本游戏，也不是 AI 陪聊产品。第一版聚焦线下聚会、校园相遇、陌生人破冰和深夜交流，让手机重新成为人与人连接的媒介。

## 当前 MVP

- 创建一个社交世界并选择关系氛围
- 自动生成邀请码和可扫描二维码
- 多人从不同设备进入同一世界
- 实时同步成员、消息和关系事件
- 因果引擎根据互动节奏推动话题
- 移动端优先，无需注册和下载

## 技术结构

- Next.js / React / TypeScript
- Cloudflare Worker 兼容运行时
- D1 持久化世界、成员和消息
- 轮询同步，适合低成本早期验证

## 本地运行

```bash
npm install
npm run dev
```

打开 `http://localhost:3000`。

## 产品原则

1. AI 不替代真人关系。
2. 世界是社交场景，不是游戏副本。
3. 用户离开时，应该带走一段共同经历。
4. 第一版先验证“人们是否愿意扫码进入并持续互动”。
